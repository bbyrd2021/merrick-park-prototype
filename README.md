# Merrick Park Baptist Church — Prototype V1

Design prototype with white overhead React Bits light rays, a cross shadow, regular Cinzel headings, Helvetica supporting type, and church photography.

This prototype contains a sample ESV verse and a Spotify placeholder. The email form does not submit or store information. No API integrations are connected.

Hosted as a static page on GitHub Pages. React Bits licensing is included in REACT-BITS-LICENSE.md. Church images and branding remain their respective owners' property.
